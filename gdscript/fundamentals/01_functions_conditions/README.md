
# Day 1 - Functions, Conditions and Problem-Solving

## Overview

This section documents my first GDScript exercises, focusing on functions, parameters, return values, conditional statements, boolean logic, and problem-solving.

The main objective was to learn how to create functions that receive information, evaluate multiple conditions, and return results based on specific requirements.

I also practiced validating input values, performing arithmetic operations, and organizing conditional logic.

## Learning Objectives

- Understand how to declare and call functions.
- Work with parameters and arguments.
- Define return types.
- Understand boolean return values.
- Use conditional statements (`if`, `elif`, `else`).
- Work with comparison operators.
- Combine conditions using logical operators.
- Perform arithmetic operations inside functions.
- Validate input values.
- Practice breaking problems into smaller conditions.
- Understand the early return pattern.

Through these exercises, I practiced creating reusable functions that evaluate input values and return meaningful results.

I also started learning how to translate written requirements into programming logic and how to organize conditions to solve gameplay-related problems.
